# CodingCamp-27Apr26-srigustinahf
Mini Project Batch 27-04-2026

Saya membangun Expense & Budget Visualizer, sebuah aplikasi web responsif yang dirancang untuk membantu pengelolaan keuangan pribadi. Aplikasi web tersebut saya fokus pada pembuatan antarmuka yang bersih untuk menampilkan total pengeluaran, riwayat transaksi, dan visualisasi data pengeluaran berdasarkan kategori. Proyek ini saya kembangkan menggunakan HTML, CSS, dan Vanilla JavaScript tanpa library eksternal untuk menjaga performa tetap ringan. Selain itu saya juga mengintegrasikan fitur kustomisasi kategori, sistem penyaringan (sorting) transaksi berdasarkan nominal atau kategori, serta dukungan mode gelap (dark mode) untuk kenyamanan visual pengguna.
